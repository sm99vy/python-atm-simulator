# 🏧 Simulador de Caixa Eletrônico em Python

Um simulador de caixa eletrônico desenvolvido em Python como exercício prático de lógica de programação.

## Funcionalidades

- Simulação de saque
- Cálculo da quantidade de cédulas necessárias
- Utilização de estruturas de repetição e condições
- Exibição do resultado da operação no terminal

## Tecnologias

- Python 3

## Conceitos praticados

- Estruturas condicionais (`if` e `else`)
- Laços de repetição (`while`)
- Operações matemáticas
- Variáveis e controle de fluxo

## Como executar

1. Tenha o Python 3 instalado.
2. Clone este repositório.
3. Execute o arquivo pelo terminal:

```bash
python caixa_eletronico.py
```

## Objetivo

Praticar lógica de programação por meio da simulação de uma operação comum em sistemas bancários.
